# 部署与配置说明 

本指南旨在快速在本地环境中启动“房价预测与爬虫系统”。

---

## 一、后端配置与启动 (Django)

### 1. 环境准备
- **Python 版本**：推荐 3.10 及以上（最低支持 3.8）。
- **数据库**：**MySQL 8.0+**。

### 2. 安装依赖
直接在 `backend` 目录下安装项目所需的库：
```bash
cd backend
pip install -r requirements.txt
```

### 3. 环境变量配置 (.env)
在 `backend/` 目录下创建 `.env` 文件，并根据您的本地 MySQL 情况修改：
```env
DEBUG=True

DB_NAME=lvhai            # 数据库名 (请先在 MySQL 中创建该数据库)
DB_USER=root             # 数据库用户名
DB_PASSWORD=你的密码      # 数据库密码
DB_HOST=localhost
DB_PORT=3306

SECRET_KEY=dev-secret-key-123456
```

### 4. 数据库初始化
```bash
# 生成并应用数据库表结构
python manage.py migrate
```

### 5. 启动后端
```bash
python manage.py runserver
```
后端 API 地址为 `http://127.0.0.1:8000/`。

---

## 二、前端配置与启动 (Vue 3)

### 1. 环境要求
- **Node.js**：推荐 18.x 或以上版本。

### 2. 安装依赖
```bash
cd frontend
npm install
```

### 3. 启动前端
```bash
npm run dev
```
- 访问地址：`http://localhost:5173`。

---

## 三、快速排查
1. **数据库错误**：请确保已手动在 MySQL 中执行了 `CREATE DATABASE lvhai;`，且 `.env` 里的密码正确。
2. **端口占用**：如果 8000 或 5173 端口被占用，请关闭相关进程后再试。
